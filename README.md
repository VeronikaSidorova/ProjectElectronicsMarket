# Электронная сеть продаж - Django REST API

Система управления иерархической сетью по продаже электроники с REST API интерфейсом и админ-панелью.

## 🏗️ Архитектура системы

### Основные модели данных

- **NetworkNode** - звенья сети (Завод, Розничная сеть, ИП)
- **Contact** - контактная информация (адрес, email, телефон)
- **Product** - продукты электроники
- **EmployeeProfile** - профили сотрудников
- **Supplier** - поставщики и связи между звеньями

### Уровни иерархии

- **Уровень 0**: Завод (без поставщика)
- **Уровень 1**: Розничная сеть или ИП, связанные напрямую с заводом
- **Уровень 2+**: Последующие звенья в цепочке поставок

### Типы звеньев сети

- `factory` - Завод
- `retail_network` - Розничная сеть
- `individual_entrepreneur` - Индивидуальный предприниматель

## 🚀 Быстрый старт

### Предварительные требования

- Python 3.8 или новее
- PostgreSQL 13+ (рекомендуется) или SQLite 3
- Poetry 1.5+ для управления зависимостями

## Установка

- Клонируйте репозиторий:
``` 
https://github.com/VeronikaSidorova/ProjectElectronicsMarket.git
```
- Установите Poetry, если он ещё не установлен.

- Установите зависимости и создайте виртуальное окружение с помощью Poetry:
```poetry install```
- Активируйте виртуальное окружение:
```poetry shell```
- Настройте переменные окружения (из .env.sample)
- Выполните миграции:
```python manage.py migrate```


## Запуск
- Запустите Django-сервер:
```python manage.py runserver```

## Параметры фильтрации для Network Nodes

* country=Россия - фильтр по стране 
* product_name=Смартфон - поиск по названию продукта 
* node_type=factory - фильтр по типу звена 
* supplier=1 - фильтр по ID поставщика 
* debt_min=1000&debt_max=5000 - фильтр по диапазону задолженности 
* search=электроника - поиск по названию звена

1. [x] Полное управление звеньями сети - создание, редактирование, удаление
2. [x] Просмотр иерархии поставок - древовидное представление связей
